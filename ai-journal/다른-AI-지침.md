# 다른 AI에게 넣어 둘 일지 지침

AI 작업 일지 문서: https://docs.google.com/document/d/1SgiQOAkc5NfMq_z0-iW_yCk7cqK-5CyA2yr67oUw3o8/edit

아래 글을 각 AI의 "항상 기억하는 설정"에 한 번만 붙여 넣으시면 됩니다.
- 챗GPT: 설정 → 개인 맞춤 설정 → 맞춤형 지침 (또는 쓰시는 프로젝트의 지침)
- 제미나이: 설정 → 저장된 정보(또는 Gem 만들기의 지침)
- 그록·퍼플렉시티: 설정의 맞춤 지침 / 프로필 지침
- 클로드 채팅: 설정 → 프로필의 "선호 사항" 맨 아래에 클로드용 한 줄 추가

---

## 챗GPT·제미나이·그록·퍼플렉시티용 (그대로 복사)

```
나는 여러 AI와 함께 일하고, 모든 작업을 구글 문서 'AI 작업 일지'에 모아 둔다.
문서: https://docs.google.com/document/d/1SgiQOAkc5NfMq_z0-iW_yCk7cqK-5CyA2yr67oUw3o8/edit

1. 설교·성경공부·행정 같은 작업을 시작할 때, 이 문서를 읽을 수 있으면 '(여기부터 새 글)' 아래 최근 글 몇 개를 먼저 읽고 흐름을 이어 가라. 읽을 수 없으면 묻지 말고 그냥 진행하라.
2. 작업이 끝나거나 내가 "일지"라고 하면, 답 맨 끝에 아래 형식의 일지 글을 하나 붙여라. 문서에 직접 쓸 수 있으면 '(여기부터 새 글)' 바로 아래에 넣고, 못 쓰면 내가 붙여넣을 수 있게 그대로 보여 주기만 하라.

[YYYY-MM-DD HH:MM] (너의 이름. 예: 챗GPT)
주제:
지시: 내가 시킨 일 한두 줄
진행: 네 답이나 진행 상황 한두 줄
상태: 진행 중 / 완료 / 막힘 / 넘김(→ 받을 AI)

다섯 줄 안팎으로 짧게. 한국 시간으로. 비밀번호·키, 성도 개인의 민감한 이야기는 쓰지 마라.
```

## 클로드 채팅 선호 사항에 덧붙일 한 줄

```
작업성 대화는 구글 문서 'AI 작업 일지'(ai-journal 스킬)에 짧게 기록하고, 작업을 시작할 때 그 일지를 먼저 읽어 흐름을 이어 간다.
```

---

## 다른 AI가 쓴 일지를 넣는 가장 쉬운 방법

- 그 AI가 보여 준 일지 글을 복사해서, 문서의 '(여기부터 새 글)' 바로 아래에 붙여 넣으신다.
- 또는 클로드에게 "챗GPT한테 ○○ 맡겼어" / "제미나이가 ○○ 해줬어" 하고 한 줄만 말씀하시면 클로드가 대신 일지에 남깁니다.
