# AI 작업 일지

## 공유 문서
- 이름: AI 작업 일지 (구글 문서, 목사님 내 드라이브)
- 문서 ID: 1SgiQOAkc5NfMq_z0-iW_yCk7cqK-5CyA2yr67oUw3o8
- 링크: https://docs.google.com/document/d/1SgiQOAkc5NfMq_z0-iW_yCk7cqK-5CyA2yr67oUw3o8/edit
- 접근: 연결된 Google Drive(읽기) / Google Docs(쓰기) 도구. 안 되면 "일지 연결이 안 됩니다" 한 줄만 말한다.
- '클로드 인수인계함'과 다르다. 인수인계함은 한 작업을 통째로 넘기는 곳, 일지는 모든 AI의 작업 흐름을 짧게 쌓는 곳이다.

## 읽기 — 작업을 시작할 때, "일지 읽어"라고 하실 때
1. Google Drive `read_file_content`(includeComments: true)로 문서를 읽는다.
2. `(여기부터 새 글)` 아래 최근 글 10개 정도로 지금 흐름을 파악한다. 다른 AI가 하던 일, 넘겨받을 일, 막힌 일을 본다.
3. 목사님께 읽었다고 보고하지 않는다. 지금 작업과 이어지는 글이 있을 때만 한 줄로 짚는다. "일지 읽어"라고 직접 하셨으면 진행 중·막힘·넘김 상태인 일만 짧게 정리해 드린다.

## 쓰기
### 언제
- 클로드 코드: 자동 기록 장치가 약 5분마다 "기록할 때가 되었다"고 알려 준다. 그때 쓴다.
- 클로드 채팅: 채팅에는 시계가 없다. 대신 (1) 작업이 하나 끝났을 때, (2) 긴 작업에서 단락이 바뀔 때(대략 5분 이상 이어진 작업), (3) 목사님이 다른 AI에게 일을 맡겼다고 하실 때, (4) "일지 써" 하실 때 쓴다. 인사·짧은 질문 하나로 끝나는 대화는 쓰지 않는다.
- 같은 작업은 한 대화에서 너무 자주 쓰지 않는다. 바뀐 것이 있을 때만 새 글을 쓴다.

### 어떻게 — 한 번의 호출로
Google Docs `update_doc`에 `replaceAllText` 하나만 보낸다(위치 계산이 필요 없다).
- 찾을 글: `(여기부터 새 글)` (matchCase: true)
- 바꿀 글: `(여기부터 새 글)\n\n` + 새 글 (줄 사이는 `\n`, 끝에는 `\n` 없음)
- 그러면 표시줄 바로 아래, 빈 줄을 두고 새 글이 맨 위에 들어간다. 지난 글은 지우거나 고치지 않는다.
- 다 쓰면 목사님께 따로 보고하지 않는다. "일지 써" 하셨을 때만 "일지에 남겼습니다." 한 줄.

### 형식 (다섯 줄 안팎)
```
[YYYY-MM-DD HH:MM] 클로드 채팅  (또는 "클로드 코드 · 저장소이름")
주제: 
지시: 목사님 지시 한두 줄 요약
진행: 답변·진행 상황 한두 줄
상태: 진행 중 / 완료 / 막힘 / 넘김(→ 받을 AI)
링크: 관련 문서·파일 (있을 때만)
```
- 시간은 한국 시간.
- 다른 AI에게 맡긴 일은 맡긴 AI 이름으로 쓴다. 예: `[2026-11-08 09:30] 챗GPT (클로드가 대신 기록)`, 상태: 넘김(→ 챗GPT).
- 설교 원고 전문, 긴 결과물은 붙이지 않는다. 구글 문서 링크만 남긴다.

## 지키는 것
- 비밀번호, API 키, 토큰은 쓰지 않는다.
- 성도 개인의 상담·건강·가정사 같은 민감한 내용은 쓰지 않는다. "한 성도 심방 준비"처럼 이름 없이 적는다.
- 설교 단톡방은 "기록을 남기지 않는다"가 원칙이다. 일지에는 "단톡방 열어 ○○ 막힌 곳 점검, 결론 한 줄"까지만 쓰고 회의 내용은 옮기지 않는다.
- 코드 설명은 하지 않는다. 무엇을 했고 어디까지 왔는지만 쓴다.
