# AI 작업 일지

여러 AI(클로드 채팅·클로드 코드·챗GPT·제미나이·그록·퍼플렉시티)와 하는 일을 **구글 문서 한 곳**에 짧게 쌓고, 어느 AI든 그 문서를 읽고 흐름을 이어 가게 하는 장치입니다.

- 일지 문서: [AI 작업 일지](https://docs.google.com/document/d/1SgiQOAkc5NfMq_z0-iW_yCk7cqK-5CyA2yr67oUw3o8/edit)
- 새 글은 맨 위. 한 글은 다섯 줄 안팎(언제·어느 AI·주제·지시·진행·상태).

## AI마다 어떻게 기록되나

| 어디서 | 기록 방식 |
|---|---|
| 클로드 코드 (이 저장소) | **자동.** 시작할 때 일지를 먼저 읽고, 작업 중 약 5분마다 스스로 일지에 남깁니다. |
| 클로드 코드 (다른 저장소·내 컴퓨터 전체) | 컴퓨터에서 `bash ai-journal/install.sh` 한 번 실행하면 모든 작업에 자동 기록이 켜집니다. |
| 클로드 채팅 | `SKILL.md`를 스킬로 등록하시면, 작업이 끝나거나 바뀔 때마다 클로드가 일지에 남깁니다. 채팅에는 시계가 없어서 5분마다가 아니라 "작업 단락마다"입니다. |
| 챗GPT·제미나이·그록·퍼플렉시티 | `다른-AI-지침.md`의 글을 각 AI 설정에 한 번 넣어 두시면, 작업 끝에 일지 글을 만들어 줍니다. 문서에 직접 못 쓰는 AI는 그 글을 붙여 넣으시거나, 클로드에게 "챗GPT한테 ○○ 맡겼어"라고 한 줄 말씀하시면 클로드가 대신 남깁니다. |

## 목사님이 하실 일 (한 번만)

1. `SKILL.md`를 클로드 스킬로 등록 (설정 → 스킬 → 업로드).
2. `다른-AI-지침.md`의 글을 챗GPT·제미나이 설정에 붙여넣기, 클로드 선호 사항에 한 줄 추가.
3. 내 컴퓨터의 클로드 코드에서도 쓰시려면 `bash ai-journal/install.sh` 한 번 실행.

## 알아 두실 것

- 자동 기록은 "답을 마칠 때" 5분이 지났는지 봅니다. 한 번에 길게 이어지는 작업은 그 작업이 끝날 때 한 번에 남습니다.
- 5분 안에 끝난 마지막 지시는 다음 클로드 코드 세션 첫 기록 때 함께 남습니다(내 컴퓨터에서). 클라우드 세션은 컨테이너가 사라지면 그 몇 분치는 빠질 수 있습니다.
- 끄고 싶으시면: 그 세션에서 `AI_JOURNAL_OFF=1`, 또는 컴퓨터 전체는 `bash ai-journal/install.sh --off`.
- 이 저장소에는 기록 내용이 저장되지 않습니다. 기록은 목사님 드라이브의 구글 문서에만 남습니다(이 저장소는 공개라서 일부러 그렇게 했습니다).
- 간격을 바꾸시려면 `AI_JOURNAL_INTERVAL`(초) 값을 바꿉니다. 기본 300초 = 5분.
